# Shared Wallets

LNbits allows sharing wallet access with granular permissions.

## Sharing a Wallet

1. Go to your wallet
2. Click **Settings** (gear icon)
3. Click **Share Wallet**
4. Enter username or email
5. Select permissions
6. Send invitation

## Permissions

| Permission | Description |
|------------|-------------|
| View | See balance and transactions |
| Receive | Create invoices |
| Send | Make payments |

## Accepting an Invitation

1. Check notifications
2. Review the invitation
3. Accept or decline
4. Shared wallet appears in your list

## Managing Shared Access

Wallet owner can:
- View all shared users
- Change permissions
- Revoke access

## Use Cases

- **Team accounts**: Multiple people managing funds
- **Family wallets**: Shared household spending
- **Business**: Employee access to company wallet

## Security

- Only share with trusted users
- Use minimum necessary permissions
- Review access regularly
