# Environment variable reference

All 338 settings that LNbits v1.6.2 reads, generated from the settings model in the official image. For what they do and when to change them, see [Environment Variables](/docs/configuration/environment).

- **Admin UI: yes** (307 settings): after the first start the value lives in the database, and the Admin UI wins over `.env` while `LNBITS_ADMIN_UI=true` (the default). See [Admin UI](/docs/configuration/admin-ui).
- **Admin UI: no** (31 settings): always read from the environment or `.env`, at every start.
- Names are case-insensitive. Lists take JSON (`["a","b"]`) or comma-separated values.
- Defaults are shown as declared; long ones are cut short.
